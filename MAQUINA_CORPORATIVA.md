# 🏢 Guia para Máquinas Corporativas com Restrições

Se você **não tem acesso de administrador** ou recebe "Acesso negado", use este guia.

---

## ✅ Solução Recomendada: VBScript (Sem Admin)

### Use este arquivo:
```
keyboard_trigger_monitorv2.vbs
```

### Como funciona:

1. **Duplo-clique** em `keyboard_trigger_monitorv2.vbs`
2. Um **menu aparece** com suas frases
3. **Selecione o número** da frase que quer digitar
4. **Clique OK** e coloque o cursor no campo
5. **Frase é digitada automaticamente!** ✍️

### Vantagens:

✅ **Não precisa de admin**
✅ **Funciona em qualquer máquina**
✅ **Usa apenas recursos nativos do Windows**
✅ **Totalmente offline**
✅ **Nenhuma instalação**

## 🔧 Troubleshooting

### ❌ "Acesso negado" no VBScript
- Clique direito no arquivo
- Propriedades → Desbloquear
- OK

### ❌ VBScript não abre
- Abra Gerenciador de Tarefas
- Procure `wscript.exe` ou `cscript.exe`
- Se não tiver, IT bloqueou

### ❌ Nada foi digitado
- Certifique-se que o **campo está ativo** (clicado)
- Aguarde 1-2 segundos após selecionar
- Tente novamente

## 📞 Alternativas Adicionais

Se sua empresa tem restrições MUITO severas:

### Opção A: Email para IT
Peça ao suporte de IT:
```
Gostaria de usar um script VBScript chamado
'keyboard_trigger_monitorv2.vbs' que não requer admin
e funciona totalmente offline. Pode desbloquear?
```

### Opção B: Python em outro diretório
Se Python estiver em `C:\Python311`, o problema pode ser:
- Pasta protegida do Program Files
- Antivírus bloqueando

Peça ao IT para instalar Python em:
```
C:\Users\seu_usuario\AppData\Local\Python\
```
